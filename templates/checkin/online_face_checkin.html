How it works
  1. Select an online booking that has been confirmed by hotel staff.
  2. Upload or capture the guest's current face image.
  3. The system first uses the selfie saved with that booking as the reference image.
  4. If the booking has no selfie, the system uses the selfie stored in the customer's profile.
  5. DeepFace compares the reference image with the current face image.
  6. If verification succeeds, an Online Check-in record is stored in the database.
  7. The booking status becomes Checked in.
  8. The room status becomes Occupied.
